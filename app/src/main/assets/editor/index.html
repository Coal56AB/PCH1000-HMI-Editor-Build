Приложение для просмотра, проверки и редактирования интерфейса экранчика ПЧ-1000. На выходе получается C-код для встраивания в микроконтроллер, который будет отрисовывать интерфейс на реальном дисплее.

Сейчас используется встроенный шаблон

Вход выполняется на сайте GitHub: там вводишь логин и пароль или используешь уже открытый аккаунт. Приложение не получает твой пароль.

Разовая настройка входа (для разработчика)

Для собственных сборок можно зарегистрировать другое OAuth-приложение. В обычной сборке Client ID уже встроен и пользователю вводить его не нужно.

  1. Открой регистрацию OAuth-приложения кнопкой ниже.
  2. Название: PCH1000 HMI Editor. Homepage URL: адрес репозитория Android-приложения. Callback URL: https://localhost (в Device Flow не используется).
  3. Включи Enable Device Flow. Зарегистрируй приложение.
  4. Скопируй Client ID в поле ниже. Это не логин и не Client Secret. Секрет создавать и передавать не надо.
Другой способ: персональный токен

Токен — ключ доступа вместо пароля. Он нужен только если вход через сайт ещё не настроен. Не отправляй его в чат и не добавляй в исходники.

  1. На GitHub открой Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Выбери срок действия, владельца и только нужные репозитории.
  3. Repository permissions: Contents — Read and write; Pull requests — Read and write. Issues — Read and write, если GitHub требует это для используемых комментариев.
  4. Скопируй сгенерированный токен и вставь ниже. GitHub показывает его только один раз.

Такой токен ограничен выбранными репозиториями. Для создания нового репозитория используй сайт GitHub или настроенный OAuth-вход; затем при необходимости обнови доступ токена.
