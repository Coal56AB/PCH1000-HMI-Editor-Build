# ПЧ-1000: переносимый C99 RGB565-рендерер

Библиотека формирует интерфейс 320×480 RGB565 и передаёт произвольные прямоугольники через callback. Драйвера дисплея, HAL, STM32CubeIDE/Keil-проекта и постоянно выделенного framebuffer в библиотеке нет.

## Что перенесено

Геометрия 47 проверяемых сцен автоматически извлечена из `HMI_F407_F103_Simulator.html` через его `CStripPreview.commands`: состояния главного экрана, U/F/SF/VF, графики, все разделы параметров и автоопределение, журнал, общая/контекстная справка, цифровая и HEX-клавиатуры, время, оси, датчики/схемы, состав отображаемых параметров, фильтр и подтверждение.

`src/hmi_scene_generated.c` не редактируется вручную. Это не набор кадров: генератор строит глобальный словарь примитивов (`line`, `fill_rect`, `round_rect`, окружности, треугольники и текст) и граф общих DOM-блоков. 47 сцен ссылаются на 810 блоков, а одинаковая команда хранится ровно один раз. Сырые RGB565-кадры находятся только в `reference` и используются тестами.

Шрифты regular/bold используют исходные 4-битные таблицы глифов; исключены только размеры, отсутствующие во всех экспортированных командах. Глифы не масштабируются. Позиционное выравнивание текста совпадает с `ui_text_weight_fit` HTML/WASM. U/F экспортируется отдельными текстовыми командами, включая HTML-зазор вокруг `/`.

Иконки и мнемосхема также не имеют цветных растровых вариантов. Их геометрия общая, а состояние и цвет выбираются при сборке сцены/динамической отрисовке. Если для новой иконки потребуется bitmap, формат допускает только одну маску покрытия с окрашиванием в RGB565 во время вывода, а не отдельные зелёную/жёлтую/красную картинки.

## Сборка и проверка

```sh
make -j2
make test
```

Используются обязательные флаги `-std=c99 -Wall -Wextra -Werror`. `test_full_frames` сравнивает каждый C-кадр с сырым RGB565 из HTML. `test_dirty_updates` строит A, применяет только dirty update и побитно сравнивает результат с полным B для каждого числового поля, часов, выбранной строки и графических выборок.

PNG, C-кадры и diff находятся в `reference/qa/{html,c,diff}`. Масштабы ×2 и ×4 созданы только `nearest-neighbor` в `reference/qa/scale_x2` и `scale_x4`.

## Интеграция

Добавьте в проект:

- `src/hmi_gfx.c`, `hmi_scene.c`, `hmi_scene_generated.c`, `hmi_dirty.c`, `hmi_dynamic.c`;
- каталог `include`;
- `src/font_data.inc` рядом с `hmi_gfx.c`.

Пример универсального backend находится в `examples/stm32_display_backend_example.c`.

```c
HmiState state;
hmi_state_defaults(&state);
hmi_init();

state.page = HMI_PAGE_HOME;
state.power_state = HMI_POWER_READY;
hmi_invalidate_all();
hmi_render_dirty(&state, display_flush, display_user);
```

Callback получает точные `x/y/width/height`, указатель RGB565 и stride. Для числа или иного поля можно явно вызвать `hmi_invalidate()`, либо перед изменением сохранить старое состояние и вызвать:

```c
HmiState old_state = state;
state.output_current = 3.74f;
state.dynamic_values = 1;
hmi_diff_and_invalidate(&old_state, &state);
hmi_render_dirty(&state, display_flush, display_user);
```

`hmi_diff_and_invalidate` объединяет старую и новую области текста с запасом под сглаживание. Пересекающиеся и близкие прямоугольники объединяются. При переполнении очереди безопасно инвалидируется весь экран.

Размер рабочего пиксельного буфера задаётся до компиляции:

```sh
cc ... -DHMI_RENDER_BUFFER_PIXELS=2048
```

Если прямоугольник не помещается, он делится по высоте. Ширина фрагмента всегда равна ширине обновляемой области, а не 320. Внутренняя разбивка по границам 16 строк сохраняет точное поведение эталонного WASM на краевых сглаженных пикселях.

`scene_override = HMI_SCENE_COUNT` выбирает сцену из полей `page`, `power_state`, `drive_mode`, `graph_page`, `param_section`, `dialog`, `selected_control`. Конкретный `HMI_SCENE_*` полезен только для QA и воспроизведения эталонов. При `dynamic_values=1` значения главного экрана, журнал и графические выборки берутся из `HmiState`; подписи/единицы графических каналов задаёт основной контроллер.

## Повторный экспорт HTML

1. Откройте инструментированный HTML и сохраните `CStripPreview.commands` каждого состояния в `reference/commands/<scene>.commands.json`.
2. Выполните:

```sh
node tools/export_html_scene.mjs reference/commands src/hmi_scene_generated.c include/hmi_scene_generated.h
python3 tools/generate_fonts.py
make test
```

Инструментирование эталона выполняет `tools/instrument_html_scene.mjs`; исходный HTML не изменяется.

## Память

Результаты текущего host build приведены в `TEST_RESULTS.md`. Полный набор примитивов, шрифтов и кода занимает примерно 515 КБ в секциях host-объектов с `-Os`; точное значение ARM ELF зависит от компилятора и линкерного скрипта. Для STM32F407 с 1 МБ Flash остаётся существенный запас. Для STM32F103 с 512 КБ итог находится у самой границы ещё до драйвера, журнала и прикладного кода, поэтому полный вариант для F103 по-прежнему не рекомендуется. Рабочая RAM библиотеки при стандартном буфере — около 10,9 КБ.
