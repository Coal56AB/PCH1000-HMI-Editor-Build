# Постоянная подпись — разовая настройка

1. Открой https://github.com/Coal56AB/PCH1000-HMI-Editor-Build/settings/secrets/actions/new .
2. Name: `PCH1000_SIGNING_BUNDLE`.
3. Secret: целиком строка из отдельно выданного `PCH1000_SIGNING_BUNDLE_PRIVATE.txt`.
4. Add secret. Теперь сделай push полного проекта в main. Если push был раньше секрета, перезапусти упавший Build APK после добавления секрета.

Закрытый ключ и пароль находятся только в секретном файле и Actions Secret. Файл содержит резервную копию ключа — сохрани её отдельно. Не загружай его в публичный репозиторий, релизы или сообщения. В исходниках хранится только публичный SHA-256 сертификата `signing-certificate.sha256`. Не меняй его и не создавай новый ключ для следующих версий.

Скрипт prepare_signing.py восстанавливает существующий PKCS12 в RUNNER_TEMP, проверяет сертификат и передаёт данные Gradle через окружение. Он не генерирует ключ. Gradle проверяет ключ повторно. verify_apk_signing.py проверяет криптографическую подпись готового APK и совпадение сертификата. Любая ошибка останавливает выпуск. Временный ключ удаляется даже при ошибке сборки. В репозиторий, архив исходников и release попадает только APK, без закрытого ключа.

Из PR собирается отдельная debug APK без доступа к постоянному ключу. Старый workflow выпуска 1.2.2 отключён. Для нового обновления увеличивай versionName и versionCode; уже опубликованный release не перезаписывается.

## Переход со старой установки

Прежние APK были подписаны разными временными debug-ключами. Их закрытые ключи в доступных файлах и сохранённых артефактах не найдены. Из сертификата APK восстановить закрытый ключ нельзя. Поэтому сначала сохрани проекты во внешнюю папку или ZIP, затем один раз переустанови приложение на release 1.2.4. Проекты из внешней папки можно открыть снова; вход в GitHub потребуется повторить.

После этого обновление: приложение находит новый release → «Скачать» → стандартное подтверждение Android → установка поверх, с сохранением данных. Скачивать каждую APK вручную из GitHub не требуется.

Без обычного подтверждения Android стороннее приложение не обещает тихую установку обновлений.
