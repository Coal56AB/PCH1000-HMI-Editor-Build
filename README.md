## Что изменилось

- После генерации для GitHub push окно «47 из 47» закрывается. Очистка выполняется и при ошибке, симулятор возвращается в живой режим без перезапуска приложения.
- На верхней панели одна кнопка «Экспорт». В окне выбирается рабочая папка или ZIP; генерация начинается только по кнопке «Экспортировать». «Отмена» не запускает генерацию.
- «Откр.» убрана с верхней панели. Рабочая папка выбирается в меню «Проект»; импорт ранее сохранённого JSON/ZIP остаётся там же.
- Повторное нажатие push во время выполнения блокируется.

## Загрузка в GitHub и релиз

Это полный архив репозитория. Распакуй его в рабочую копию и сделай commit/push в main. Build APK проверит код, соберёт APK 1.2.3 и затем опубликует release v1.2.3 с этим APK, полным архивом исходников того же коммита и SHA256SUMS.txt. Сначала создаётся draft с файлами, затем он публикуется как latest. Уже опубликованная версия не перезаписывается при следующих сборках; для нового релиза надо увеличить versionName и versionCode.

Основной сценарий: `.github/workflows/build-apk.yml`. Исторический `publish-v1.2.2.yml` сохранён и запускается только вручную; новая публикация не зависит от старых run ID и срока хранения артефактов.

Подпись пока debug и создаётся заново в GitHub Actions. APK не установится поверх версии с другим ключом. Постоянный ключ подписи ещё не настроен; не добавляй закрытый ключ в публичный репозиторий.

# ПЧ-1000 HMI Editor для Android

Приложение для просмотра, проверки и редактирования интерфейса экранчика ПЧ-1000.
На выходе получается C-код для встраивания в микроконтроллер, который будет
отрисовывать интерфейс на реальном дисплее.

## Возможности

- живая интерактивная симуляция: вкладки, графики, клавиатуры и диалоги работают как в исходной HTML-версии;
- отдельный переход в режим редактирования без выбора одной из 47 QA-сцен вручную;
- внешние кнопки `ЗАРЯД / РАЗРЯД`, `ПУСК / СТОП` и цифровой энкодер с переключением по удержанию 0,5 с;
- максимальный целочисленный масштаб: один пиксель TFT отображается блоком 2×2, 3×3 и т. д. физических пикселей телефона;
- точный предпросмотр через исходный полосовой WASM/RGB565-рендерер;
- автоматическое определение текущего состояния; 47 контрольных сцен используются внутри экспортера;
- выбор элемента касанием;
- перемещение, изменение ширины/высоты, точные координаты и сетка;
- изменение собственного текста, размера и насыщенности шрифта;
- независимое пиксельное смещение текста по X/Y внутри блока без перемещения самого блока;
- точный дополнительный зазор после выбранного символа, например 1 px после `/`;
- цвета текста, фона, рамки, SVG-линии и SVG-заливки;
- глобальные изменения и отдельные переопределения для каждого сценария;
- undo/redo и автоматическое локальное сохранение;
- импорт JSON-проекта или ранее экспортированного ZIP;
- экспорт ZIP с JSON-проектом и готовым C99-рендерером;
- прямой экспорт тех же исходников обычными файлами в выбранную папку Android.
- постоянная рабочая папка: проект редактора сохраняется туда автоматически, а полный C-проект — по команде;
- вход в GitHub через OAuth Device Flow или personal access token, выбор/создание репозитория и ветки, pull, commit и push;
- закреплённый репозиторий обновлений APK через Releases (не связан с пользовательским C-проектом);
- необязательный режим `Codex — БЕТА`: отдельная ветка, Draft PR и задача через `@codex`;
- сравнение результата `БЫЛО / СТАЛО` и подсветка изменившихся пикселей;
- короткое обучение при первом запуске, которое можно повторить из настроек.

## GitHub

Разработчик один раз регистрирует GitHub OAuth App и включает Device Flow.
Публичный Client ID можно включить в APK через переменную окружения
`GITHUB_OAUTH_CLIENT_ID` или `gradle -PgithubOAuthClientId=… assembleDebug`.
Тогда пользователь видит кнопку входа через сайт GitHub без ввода Client ID.
Client secret для Device Flow не нужен и в APK не хранится.
В сборке без настроенного ID показана честная разовая инструкция, а не форма ввода логина.
Также доступен вход с fine-grained или classic personal access token. Токен шифруется
ключом Android Keystore.

Codex-режим по умолчанию выключен. После включения приложение создаёт отдельную ветку
и Draft PR, добавляет комментарий `@codex` и показывает текстовый дифф. Для визуального
сравнения ветка должна содержать синхронизированный `PCH1000_HMI_editor_project.json`.
Слияние выполняется только после явного нажатия пользователя.

Обновление APK проверяется по последнему GitHub Release репозитория
`Coal56AB/PCH1000-HMI-Editor-Build`, закреплённого в Android-коде. Авторизация не нужна.
Пользователь выбирает только репозиторий своего C-проекта; этот выбор не влияет на обновления APK.
Установка всегда подтверждается системным установщиком Android.

## Сборка

Откройте каталог в Android Studio (JDK 17, Android SDK 35) и выполните
`Build > Build APK(s)`, либо запустите `gradle assembleDebug`.

Готовый debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Экспорт из приложения

Кнопка `Экспорт` открывает выбор места сохранения и подтверждение. После подтверждения
редактор воспроизводит все контрольные состояния и применяет глобальные и сценарные правки.
При выборе ZIP предлагается сохранить `PCH1000_HMI_edited.zip`. В обоих вариантах сохраняются:

- `PCH1000_HMI_editor_project.json`;
- `PCH1000_HMI_C_Renderer_edited/src/hmi_scene_generated.c`;
- `PCH1000_HMI_C_Renderer_edited/include/hmi_scene_generated.h`;
- остальные заголовки, графический движок и динамический слой C-рендерера.

Вариант «В рабочую папку» сохраняет тот же полный набор без ZIP в папку из меню «Проект».
Одноимённые файлы обновляются. Если папка ещё не выбрана, генерация не начинается.

Приложение не сохраняет полноэкранные пиксельные кадры в C-коде. Экспорт состоит
из линий, прямоугольников, окружностей, треугольников и текстовых команд.
