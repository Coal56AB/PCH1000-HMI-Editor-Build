# 1.2.2 — вход GitHub

- В APK по умолчанию встроен публичный OAuth Client ID редактора; настройки ID скрыты для обычного пользователя.
- Сетевой сбой DNS/соединения или таймаут при ожидании подтверждения больше не завершает вход: повторные запросы идут до истечения кода, с увеличением интервала.
- Добавлены копирование кода и открытие GitHub одной кнопкой, повторное копирование и отмена входа.
- Повторные нажатия входа не запускают несколько параллельных попыток; отменённая попытка не сохраняет токен.
- Ошибки входа показаны по-русски; блок кода прокручивается в видимую область.
- Все исходники версии 1.2.1 и BuildConfig Build Fix сохранены.

# Изменения

## 1.2.1

- добавлена собственная адаптивная иконка TFT с графиком и монохромным вариантом;
- сохранён Build Fix: включена генерация BuildConfig;
- центрирование HMI больше не зависит от момента загрузки iframe;
- геометрия пересчитывается при изменении размеров рабочей области;
- обучалка резервирует место для карточки, не закрывает кнопки и прокручивает панель к выбранному элементу;
- добавлены инструкции входа GitHub, проверка Client ID и возможность задать его при сборке APK;
- OAuth-вход без ручной настройки пока требует регистрации приложения разработчиком;
- репозиторий обновлений закреплён: Coal56AB/PCH1000-HMI-Editor-Build;
- обновления проверяются без авторизации, токен C-проекта не передаётся при скачивании APK;
- добавлены автоматические проверки геометрии и обучалки в браузере.

## 1.2.0

- добавлена постоянная рабочая папка и автоматическое сохранение проекта редактора;
- добавлен полный экспорт C-проекта в выбранную папку без удаления посторонних файлов;
- исправлен ввод чисел: значение применяется после завершения редактирования поля;
- добавлено независимое смещение текста внутри блока по X/Y;
- удержание энкодера для переключения параметра сокращено до 0,5 секунды;
- улучшена видимость пробелов в параметрах и фильтре журнала;
- сохранены системные панели Android и безопасные верхний/нижний отступы;
- добавлены GitHub-авторизация, выбор и создание репозитория, ветки, pull, commit/push и история;
- добавлены отдельный репозиторий обновлений и установка APK из GitHub Releases;
- добавлен отключённый по умолчанию режим Codex-бета через отдельную ветку и Draft PR;
- добавлены текстовый diff, сравнение рендеров «было/стало» и пиксельный diff;
- добавлено короткое обучение при первом запуске.
