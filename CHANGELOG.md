# 1.2.4 — постоянная подпись обновлений

- Release использует один сохранённый ключ из PCH1000_SIGNING_BUNDLE; случайная подпись больше не публикуется.
- Сертификат закреплён в исходниках и проверяется при восстановлении ключа, в Gradle и на готовом APK.
- Без секрета или с другим ключом сборка и публикация завершаются ошибкой.
- Закрытый ключ не входит в репозиторий или release; временная копия очищается.
- Debug-сборки имеют отдельный applicationId `.debug`. Старый сценарий публикации случайного debug APK отключён.
- Переход со старых временных подписей однократный; дальнейшие release совместимы по подписи.

# 1.2.3 — экспорт и GitHub push

- Генерация сама закрывает прогресс в finally, в том числе после ошибок и при вызове из GitHub push; живой симулятор восстанавливается.
- Одна кнопка «Экспорт», выбор рабочей папки/ZIP и явное подтверждение до генерации. Удалена верхняя кнопка «Откр.», импорт остаётся в меню проекта.
- Защита от параллельной генерации и повторного push.
- Build APK публикует новую версию после успешной сборки с APK и всеми исходниками того же коммита. Уже опубликованные версии не перезаписываются.
- Добавлены регрессионные тесты генерации, подтверждения и GitHub push.

# 1.2.2 — вход GitHub

- В APK по умолчанию встроен публичный OAuth Client ID редактора; настройки ID скрыты для обычного пользователя.
- Сетевой сбой DNS/соединения или таймаут при ожидании подтверждения больше не завершает вход: повторные запросы идут до истечения кода, с увеличением интервала.
- Добавлены копирование кода и открытие GitHub одной кнопкой, повторное копирование и отмена входа.
- Повторные нажатия входа не запускают несколько параллельных попыток; отменённая попытка не сохраняет токен.
- Ошибки входа показаны по-русски; блок кода прокручивается в видимую область.
- Все исходники версии 1.2.1 и BuildConfig Build Fix сохранены.
